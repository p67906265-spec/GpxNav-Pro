GPX NAV PRO - IMPORTAZIONE GPX

Questa versione aggiunge:
- pulsante "Importa GPX";
- selezione di file .gpx dalla memoria del dispositivo;
- lettura di tracce trk/trkseg/trkpt e rotte rte/rtept;
- copia persistente del GPX nella memoria privata dell'app;
- linea blu del percorso;
- punto verde di partenza;
- punto rosso di arrivo;
- zoom automatico sull'intero percorso;
- calcolo della lunghezza totale della traccia;
- riapertura automatica dell'ultimo GPX importato.

Nota: questa fase gestisce un GPX attivo alla volta. La navigazione lungo il percorso,
le distanze Inizio/Fine e gli avvisi verranno aggiunti nelle fasi successive.
